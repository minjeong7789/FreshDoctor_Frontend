# FreshDoctor Frontend

신선식품 유통기한 관리 서비스의 프론트엔드입니다.

## 기술 스택
- React + TypeScript
- Vite
- GitHub Actions (CI/CD)

## 실행 방법
```bash
npm install
npm run dev
```

## 환경 변수
`.env.example`을 참고해 `.env` 파일을 생성하세요.
